# รายงานผลการทดสอบระบบวิเคราะห์ข้อมูลเชิงคุณภาพ (Yii2)

วันที่ทดสอบ 9 พฤศจิกายน 2569 · branch `yii2-rewrite` · PHP 8.4.14, MySQL 9.5, Yii 2.0.54

**สรุป:** ระบบใหม่ผ่านการทดสอบอัตโนมัติครบ 99/99 รายการ (617 assertions)
และเปิดได้ทุกหน้าบนข้อมูลจริงทั้ง 623 โครงการ (4,361 requests, ไม่มี error)
ข้อมูลที่ย้ายจากระบบเดิมตรงกันทุกโครงการ ไม่มีเนื้อหาสูญหายหรือถูกเปลี่ยน
ระหว่างทดสอบพบข้อบกพร่อง 4 จุดและแก้แล้ว เหลืองานตั้งค่า 6 ข้อก่อนเปิดใช้งานจริง (หัวข้อ 7)

> **ปรับปรุง 10 พ.ย. 2569:** เลิกใช้การเข้าระบบด้วยรหัสผ่าน — เข้าได้เฉพาะ Gmail / LINE และผู้ดูแลอนุมัติ
> (อนุมัติแบบ "รวมกับบัญชีเดิม" ได้) คอลัมน์รหัสผ่านถูกลบออกจากฐานข้อมูลแล้ว รวมถึงรหัสผ่านเดิมแบบไม่เข้ารหัส
>
> **ปรับปรุง 10 พ.ย. 2569 (2):** ทุกตาราง (13 ตาราง) มี `flagDel` ปุ่มลบทุกจุดแค่ซ่อนข้อมูล ไม่ลบแถวจริง
> ทดสอบเพิ่ม 12 รายการ (`SoftDeleteTest`, `SoftDeleteCest`) และเปิดทุกหน้าของทั้ง 623 โครงการบนข้อมูลจริง
> (6,858 หน้า) ไม่มี error จำนวนข้อมูลก่อน/หลังเปลี่ยนโครงสร้างตรงกันทุกตาราง

## 6. ความปลอดภัย

| การตรวจ | ผล |
|---|---|
| CSRF: POST โดยไม่มี token | ปฏิเสธ (400) ทุกกรณี ไม่มีข้อมูลถูกบันทึก |
| SQL injection: 7 รูปแบบในช่องค้นหาและพารามิเตอร์ | ไม่มี SQL error, ไม่มีข้อมูลรั่ว |
| XSS: ข้อความ HTML ในช่องค้นหาและในคำตอบ | แสดงเป็นข้อความ (escape) ทุกจุด |
| สิทธิ์เข้าถึงโครงการของคนอื่น (IDOR) | 403 ทุก route |
| Open redirect ผ่าน `returnUrl` / Referer | ถูกบล็อก กลับหน้าหลักแทน |
| Cookie (`PHPSESSID`, `_identity`, `_csrf`) | HttpOnly ทั้งหมด; `_csrf` SameSite=Lax |
| รหัสผ่าน | ไม่มีแล้ว: เข้าได้เฉพาะ Gmail/LINE, คอลัมน์รหัสผ่าน (รวมรหัสเดิมแบบไม่เข้ารหัส) ถูกลบจากฐานข้อมูล |
| Google/LINE ยึดบัญชีด้วยอีเมลที่ไม่ยืนยัน | ทำไม่ได้ |
| คำสั่งย้ายข้อมูลแสดง SQL ตอน error | ไม่แสดงค่าแล้ว และไม่นำเข้ารหัสผ่านเดิมอีก |
| ผู้ใช้ทั่วไปอนุมัติ/รวมบัญชีเอง | ทำไม่ได้ (403) |

ยังไม่มี: Secure flag บน cookie (ต้องใช้ HTTPS), security headers (`X-Frame-Options`, `Content-Security-Policy`),
และ header `X-Powered-By` ยังบอกเวอร์ชัน PHP — อยู่ในรายการหัวข้อ 7
(การเดารหัสผ่านไม่เป็นความเสี่ยงอีกแล้ว เพราะไม่มีการเข้าด้วยรหัสผ่าน)

## 7. สิ่งที่ต้องทำก่อนเปิดใช้งานจริง

- [ ] ตั้ง `YII_DEBUG` เป็น `false` และ `YII_ENV` เป็น `prod` ใน `web/index.php` (ตอนนี้เปิด debug toolbar และ Gii อยู่)
- [ ] เปิดใช้ผ่าน HTTPS และตั้ง cookie เป็น Secure (`request.csrfCookie`, `session.cookieParams`, `user.identityCookie`)
- [ ] เพิ่ม security headers ที่ web server: `X-Frame-Options: SAMEORIGIN`, `X-Content-Type-Options: nosniff`, ปิด `expose_php`
- [ ] ใส่ client ID / secret ของ Google และ LINE ใน `config/params-local.php` แล้วทดสอบ login จริง
- [ ] ตั้งผู้ดูแลคนแรก: `php yii user/admin <gmail> <username เดิม>` (ยังไม่มีใครเข้าระบบได้จนกว่าจะทำข้อนี้)
- [ ] ลบฐานข้อมูล `nurseapp_legacy` หลังย้ายข้อมูลเสร็จ (ยังเก็บรหัสผ่านเดิมแบบไม่เข้ารหัส)

## 8. ขอบเขตที่ยังไม่ได้ทดสอบ

- Login ด้วย Google/LINE กับเซิร์ฟเวอร์จริง (ยังไม่มี client ID) — ทดสอบแล้วเฉพาะ URL ที่ส่งไปและตรรกะจับคู่บัญชี
- เบราว์เซอร์อื่นนอกจาก Chromium และมือถือจริง (ทดสอบเฉพาะขนาดจอ)
- ผู้ใช้หลายคนแก้ข้อมูลเดียวกันพร้อมกัน และโหลดสูงบนเซิร์ฟเวอร์จริง (ทดสอบบน PHP built-in server ที่รับทีละ request)
- การ deploy บนเซิร์ฟเวอร์จริง (Apache/Nginx, PHP-FPM, OPcache)
